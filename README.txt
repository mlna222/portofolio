MAULANA.SYS PORTFOLIO — STATIC DEPLOY PACKAGE

Files:
- index.html       Main portfolio website (HTML, CSS, JavaScript in one file)
- cv-maulana.pdf   Public CV download used by the website
- Maul.jpg         Profile photo used on the about card
- robots.txt       Allows search engine crawlers to access the site
- vercel.json      Security headers for Vercel deployments

Local preview:
1. Keep the listed files in the same folder.
2. Open index.html in a modern browser.
3. For best results, serve the folder locally or deploy it as a static site.
   Google Fonts requires an internet connection; fallback fonts are included.

Vercel deployment:
1. Create a GitHub repository and upload index.html, cv-maulana.pdf, Maul.jpg, robots.txt, and vercel.json to its root.
2. Import the repository in Vercel.
3. Choose Other / Static Site if prompted. No build command is needed.
4. Set the output directory to the repository root (or leave the default if detected).
5. Deploy and test the CV download and contact buttons.
